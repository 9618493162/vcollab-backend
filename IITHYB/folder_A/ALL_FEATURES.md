## 🎯 **How to Use Each Feature**

### **During a Meeting:**

1. **Toggle Microphone**
   - Click 🎤 button
   - White = On, Gray = Off

2. **Toggle Camera**
   - Click 📹 button
   - White = On, Gray = Off

3. **Share Screen**
   - Click 🖥️ button
   - Select screen/window
   - Click "Share"

4. **Send Reaction**
   - Click 😊 button
   - Select emoji
   - Watch it float up!

5. **Raise Hand**
   - Click ✋ button
   - Button turns yellow
   - All participants notified

6. **Send Chat Message**
   - Type in input
   - Press Enter or click ⬆
   - Message appears instantly

7. **Upload File**
   - Click 📎 Files tab
   - Click upload area
   - Select files
   - Files shared instantly

8. **View Summary**
   - Click 📋 Summary tab
   - See all statistics
   - Read AI insights

9. **See Participants**
   - Click 👥 button
   - View all participants
   - Use host controls (if host)

10. **Start Recording**
    - Click ⏺️ button
    - Accept permissions
    - Red indicator appears
    - Click again to stop & save

11. **Open Settings**
    - Click ⚙️ button
    - Change devices
    - Enable background blur
    - Choose virtual background

12. **Switch Layout**
    - Click 🔳 button
    - Toggle Grid ↔ Speaker view
    - Automatic or manual

13. **Enable Captions**
    - Settings → General
    - Check "Enable Closed Captions"
    - Captions appear at bottom

14. **Blur Background**
    - Settings → Video
    - Click "Enable Background Blur"
    - Button turns green

15. **Add Virtual Background**
    - Settings → Video
    - Click "Choose Virtual Background"
    - Select image file
